# Canvas gallery surface

Scope: the Canvas rail panel, full-screen page, setup view, and Work Status section. Mode: Operate. The visual world is OpenChamber's own; this is a native surface inside it, not a new brand.

## Direction contract

THESIS: A native artifact shelf and inspector. The gallery reads as part of OpenChamber, not a small admin dashboard. It refuses the generic stack of tiny labels, a row of equal buttons, and a raw JSON setup dump.

OWN-WORLD: OpenChamber theme tokens only. Restrained neutrals, the app font, 9px radii, 1px borders, primary only for selection and primary actions. Kind color lives in a small icon tile, never as a card edge.

STORY: Scan recent artifacts, see what is new or has feedback, open one in the browser panel, inspect its version ladder, and ask the agent for the next change. Setup is a guided check, not a config page.

FIRST VIEWPORT: A compact header with the Canvas mark, name, count, plus, and menu. A full-width search. A scope and tag filter row. A grouped list of favorites and artifacts with kind tiles. At wide widths, a persistent inspector pane; at rail width, the inspector replaces the list with a back control. The primary action is Open.

FORM: Master-detail workspace inside an established app system; a list that behaves like a shelf and a detail that behaves like a workbench. The signature is the version ladder: newest first, current version pinned, older versions restorable in place.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
